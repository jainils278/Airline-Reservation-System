# ✈️ Airline Reservation System

A console-based Java application that simulates an airline reservation system with user registration, flight booking, seat selection, booking management, food selection, and an admin panel.

## 📌 Features

- 👤 User registration and login
- 🔐 Admin login and dashboard
- ✈️ Domestic flight booking
- 🌍 International flight booking
- 🎫 Flight ticket reservation
- 💺 Seat selection
- 🪟 Window and aisle seat charges
- 📋 View existing bookings
- ❌ Cancel bookings
- 🍱 Vegetarian and non-vegetarian food menus
- ✅ Input validation for user details
- 📊 Flight and seat availability tracking

## 🛠️ Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Java Arrays
- Console / Command-Line Interface

## 🧠 OOP Concepts Used

The project demonstrates several Object-Oriented Programming concepts, including:

- **Inheritance**
- **Polymorphism**
- **Classes and Objects**
- **Constructors**

## 👤 User Features

Users can:

1. Create an account
2. Log in
3. Choose between domestic and international flights
4. Select a flight
5. Enter passenger details
6. Select seats
7. Choose food
8. View bookings
9. Cancel bookings
10. Log out

## 👨‍💼 Admin Features

The system provides a separate admin login and admin functionality for managing the airline reservation system.

## 💺 Seat Management

The system tracks booked and available seats and applies additional charges for selected seat types such as window and aisle seats.

## 🍱 Food Menu

Passengers can select from:

- Vegetarian food
- Non-vegetarian food

Each food item has its own price.

## 💾 Data Storage

The application currently uses Java arrays for storing users, flights, bookings, and food menu information during program execution.

It does not use an external database.

## ▶️ How to Run

### Requirements

- Java Development Kit (JDK)
- Any Java IDE or terminal

### Steps

1. Download or clone this repository.
2. Open `AirlineReservationSystem.java`.
3. Compile the Java file.
4. Run the `AirlineReservationSystem` class.
5. Follow the instructions displayed in the console.
